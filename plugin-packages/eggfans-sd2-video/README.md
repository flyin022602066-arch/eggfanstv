# EggFans SD2 视频

EggFans SD2 异步视频协议包。默认 API 地址为 `https://vip.eggfans.asia`，在渠道配置中填写 API Key。

视频节点的「视频设置 → 输出」提供“过人脸”开关，默认关闭，并记住用户上一次选择。SD2 渠道的 A、B、C、D、E 均保留该开关。软件内部以布尔 `config.face` 传给后端；仅开关开启且实际提供参考图片、参考视频或首帧时，向 `POST /v1/videos` 添加 `native_face: true`。关闭、纯文本、仅音频、仅尾帧时省略该字段。切换模型不清除已保存的偏好；其他渠道不使用该参数。本地网格遮罩不会强制关闭原生开关；具体模型是否接受参数及能否生成仍取决于上游。

支持 `sd-2.5-A` 至 `sd-2.5-E`、4–30 秒视频、固定 720p、公网 HTTPS 参考素材，以及文档声明的首尾帧和多素材参考模式。桌面模式下本地图片、视频和音频会在提交前自动上传到 Uguu 获取临时 HTTPS URL；链接每次使用前都会校验，失效或临近过期时自动重传。此通道只提交 URL，不使用 Eggfans Seedance 私域 `asset://` 资产。
