# 佳速视频

独立的视频渠道，支持 `dola-sd-2.5`、`dola-sd-2.0`、`minimax-h3`、`sd-2.5-j2-V` 和 `sd-2.5-J2`。在模型配置中单独填写该渠道的 URL、API Key 和请求头，默认地址为 `https://ai.jiasuapi.com`。

创建与查询采用佳速原生协议，不复用 Eggfans Seedance 或 Eggfans SD2 的请求结构。参考图片、视频、音频只提交公网 URL；本地素材在生成前自动通过 Uguu 获取链接，已保存链接失效时按现有临时素材流程重新上传。不会调用私域人像库，不提交 `asset://` 或 SD2 的 `native_face`。

视频设置提供佳速专属「人脸处理」选项：服务端默认、保持原图、轻度处理、素描处理。节点记录自己的选择，新节点继承最近选择。

佳速的 `dola-sd-2.5`、`dola-sd-2.0` 默认启用本地自动人脸遮罩。视频节点的「人脸遮罩」可以预览多张参考图、移动或缩放人脸框、手动补框，也可选择马赛克或关闭。调整与开关会保存，原始图片保留。预览阶段不上传图床，开始生成后先保存处理副本，再由视频任务准备有效公网 URL；链接失效时重新上传处理副本。此功能不应用于 H3、Eggfans SD2 或 Seedance URI 通道，也不替代服务端的 `face` 参数。

完整请求和模型限制见 [docs/interface.md](docs/interface.md)。

`sd-2.5-j2-V` 和 `sd-2.5-J2` 均支持 30 张图片、10 段视频和 10 段音频参考；V 版参考素材总大小上限为 100 MiB。两者时长为 5–30 秒，V 版固定 720p，J2 版提供 480p、720p、1080p。`dola-sd-2.5` 时长支持选择 1–30 秒，30 秒以 `duration: 30` 提交。`dola-sd-2.0` 保留 1–15 秒，H3 保持固定 15 秒。
