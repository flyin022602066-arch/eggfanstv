# 摄影色彩与画面连续性质检

以剧情、资产身份和已确定风格为基准，定位影响阅读与剪辑的具体问题。区分原片、显示变换、艺术选择和生成错误；质检有证据，修正保持项目合同。

## 检查模式

- 只有文字或分镜：检查摄影指令冲突、空间、光向和状态，只能报告设计预检。
- 有图片：检查该帧可见内容、曝光呈现、颜色和构图，不能由单帧判断闪烁或完整运动。
- 有可访问视频与相邻镜：检查起、中、落幅及剪辑前后；无法逐帧读取或播放时说明限制。未经授权不生成替代媒体、不上传第三方、不改原片。

## 检查顺序

1. 确认剧情、身份、画幅、风格、字幕、交付和阶段。台词、系统数值及屏幕文字属于剧情事实，不为“干净画面”删除；生成文字仍需人工核对。
2. 先查叙事与身份：人物数量、脸、服装、道具状态、持物手与因果。重复人物、消失物体和错误文字不是调色能修复的问题。保留真实资产 ID 和参考绑定，定位具体镜头或冲突指令。
3. 查摄影空间：画面方向、视线高度、轴线、主体大小、焦点、遮挡及出入画。分别记录上一镜落幅与下一镜起幅，不能因单帧都漂亮就判定能接。剪辑允许压缩动作时间，但要保留剧情上的连续性依据。
4. 查照明：世界光源位置、阴影方向、软硬、背景层次、眼神光与反射。变化必须有来源，反打不翻转真实窗位。人物转身可合理改变受光，不能把一切阴影差异判成错误。
5. 查曝光与色彩：先确认素材色彩空间、输入变换、监看及输出目标，再比较肤色、白衣、中性物和背景。HDR/SDR、Log/显示画面不能直接硬比数值。缺少原片和显示链时出视觉诊断，不编造参数。
6. 基础匹配先于创意风格：先处理曝光、白平衡、绿/品红、黑白端和通道剪切，再匹配稳定对象的相对明暗与色相，最后调局部对比、饱和与质感。LUT 不能恢复已剪切信息，也不能掩盖错误输入变换。
7. 真实视频检查闪烁、曝光呼吸、白平衡漂移、肤色跳变、面部服装变形和运动模糊。首尾关键帧不能证明整段稳定，画面静止不能代替完整播放。
8. 修正后复查肤色污染、光晕、蒙版跳动、锐化、暗部噪声与色带。颗粒或有意偏色可以是风格，不按个人审美一律清除。

## 输出与修正

每项使用“镜号/位置或已有时间点｜问题｜证据｜影响｜最小修正｜复查结果/待验证”。按阻断叙事、影响连续、细节优化排序，不给无依据的“电影感分数”。无实际媒体时结果写“待画面验证”。

提示词精修返回需要修改的最短段落及原因，保留其余剧情、对白、时长、资产绑定和 schema。调色建议说明顺序与复查对象，不声称已处理文件。实际编辑得到授权后先保留原文件，再用真实输出播放或逐帧核对。

合同禁止正文时间码时，用镜号及起/中/落幅定位；成片诊断允许时间点时沿用已有时间码。完整示例见 [连续性验收](references/continuity-review.md)。

## 通过条件

剧情与身份未被改写，空间可读，光线变化有来源，相邻镜曝光与色彩符合场景逻辑，每项修正有复查证据。分开报告“文字检查”“单帧检查”“视频播放”和“输出验证”，不把部分通过写成全部通过。
