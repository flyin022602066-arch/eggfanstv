# 电影光影设计与精细布光

把叙事目标转成可描述、可调整、可复核的光线关系。先让人物、空间和关键动作读得懂，再设计明暗秩序与光效。真实摄影参数和视频模型自然语言提示分开表达，不伪造模型不支持的控制项。

## 输入与判断边界

沿用时间、天气、场景方位、窗门位置、服装材质、画幅、风格、参考资产和输出合同。区分现场照片、风格参考、草图和生成结果；单张图不能证明完整灯位或真实色温，未知参数须标为估计。只做文本设计和画面诊断，不自行生成、上传或改变任务状态。

## 布光与调节

1. 确定光源动机，例如已有窗光、灯具、屏幕或街灯，以及叙事要保留的暗部。区分画内实景灯与画外塑形灯；画外补光允许存在，但方向、颜色与强度应融入场景。说明光从哪里来、照到谁、为何变化。
2. 给出主体、摄像机和灯光的相对位置。明确画面左右、人物左右或世界方位的参照系；主光写角度、高度、软硬与落点。反打换摄影侧不等于窗户和真实主光跟着翻转。
3. 分配主光、辅光或负补光、轮廓和背景的职责。辅光控制暗侧信息；负补光减少环境反射；轮廓光仅在需要分离时使用，不对所有物体统一描边。用旗板和遮挡控制溢光，背景亮点不能抢走关键动作。
4. 根据光源相对主体的角尺寸、距离及遮挡判断软硬。大面光源靠近通常使影缘更柔，但覆盖和衰减也变化；扩散、反射与负补光解决不同问题。平方反比仅作小尺度光源近似，不能直接套到贴近的大面积灯、复杂反射或天空。
5. 说明光比口径。两盏灯分别的入射贡献与脸部亮暗侧总照度不是同一比例；“主光比辅光强两档”不能直接等同“脸部亮侧比暗侧亮两档”。未知相机、显示变换和测光条件时，不用固定 IRE 判定所有肤色。
6. 先锁定白平衡基准，再安排光源暖冷关系。色温不等于光谱完整，混合光还须检查绿/品红偏移及肤色。暖冷对比要有来源，不给所有场景套橙青。跨镜保留基准，避免自动白平衡漂移。
7. 曝光围绕人物、服装和叙事关键高光判断，保留必要暗部与高光层次；夜戏不是单纯欠曝。实拍结合波形、假色、RGB 通道和当前 Log/显示变换。优先调光量、ND 或照明，而非无目的改快门；调光圈时同时复核景深。
8. 材质分别处理：眼镜检查反射遮眼；皮肤高光先调灯位、面积和化妆；金属与玻璃控制其反射的形状与环境；黑衣靠明度层次和背景分离；白衣保留纹理。不用全局提亮解决局部反光。
9. 动态光效写清来源、方向、范围、触发和结束状态。屏幕闪动、车灯扫过或雷光不能造成无来源全场曝光跳变。实拍检查灯具调光、供电、帧率和快门组合的频闪；提示词不能保证硬件无频闪。
10. 人物或摄影移动时，逐个关键位置复核脸部曝光、光向、眼神光、遮挡和穿帮，保证完整路径成立，再微调起落幅。尊重项目风格，不用“更真实”否定用户的动画或风格化选择。

## 精修与交付

先定位主体太平、阴影堵塞、肤色污染、背景抢亮、高光丢失、反光遮眼或跨镜漂移。每条建议采用“证据 → 原因假设 → 最小调整 → 预期变化 → 复查指标”，优先一次修改一个主要变量，不把调色当万能补救。

独立方案输出光源动机、文字灯位图、主辅与明暗关系、色彩/曝光基准、材质控制和连续性检查。实拍参数注明设备与测试前提；AI 提示词写可见结果，如“窗侧脸颊柔亮，背光侧保留眼窝和衣料，后墙暗于人物，暖灯保留灯罩纹理”。

已有分镜或 JSON 时只补充既有光线、首帧或动态提示词字段，保留资产 ID、对白、时长及 schema。首帧描述当前光态，变化放入视频提示词。需要夜戏、光比或局部精修推演时，读取 [布光推演与诊断](references/lighting-review.md)。

交付前确认同场光向、白平衡、阴影和动态光效能跨镜接上。没有原片或真实生成时，明确方案与待验证项，不报“画面已通过”。
