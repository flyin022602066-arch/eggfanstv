# 电影级运镜与场面调度

让摄影运动改变观众对人物、空间或信息的认识。先判断固定机位能否完成任务，再决定移动；稳定器、轨道和手持是实现方式，不是叙事目的。

## 边界

沿用剧情、资产、场景、画幅、输出合同与模型能力。只做文本设计，不自行生成视频或上传参考。尊重用户明确的静止摄影选择。时长、镜头数量和节奏按任务确定，不强加任意秒数、切镜频率或器材型号。

## 运动设计

1. 给本镜一个主要任务：靠近情绪、拉开揭示处境、随动作保持关系、越过遮挡揭示事实，或转移注意力。无任务时选固定机位。情绪词转换成观众实际看到的变化。
2. 分开描述演员轨迹与摄影轨迹，交代摄影起点、方向、路径、终点、主体大小及背景变化。“跟随”须说明跟谁、哪侧、保持什么距离或构图，不让人物因摄影指令无故瞬移。
3. 区分位移、转动、变焦和移焦：推拉改变机位；摇镜从同一机位转动视线；横移产生前后景视差；变焦改变视场而非推进；移焦改变清晰区域，不自动改变机位或景别。
4. 按叙事选方法：推进收紧注意；拉远引入环境；横移显露遮挡或分离层次；摇镜转移可见信息；跟拍维持行动关系；环绕逐渐改变空间关系。手持扰动与人物状态一致，不默认持续剧烈抖动。
5. 写明启动和停止的动作依据，如“人物抬眼时开始”“越过门框后停住”。用缓起、匀速、缓停表达速度感；由动作落点、目光、构图或连续声音决定切点。无要求时不堆砌机械速度值和时间码。
6. 调度包括起位、目光、转身、绕行、道具交接、前景掠过和焦点承接。人物移动可以替代摄影运动。多人场面让关键行动有清晰背景与无遮挡轮廓，不让所有人同时抢画面。
7. 每镜优先一种主运动。实拍长镜头确需多阶段路径时，用可识别动作节点说明先后，不并列冲突的同时运动。当前合同或视频模型要求单镜一种运镜时，拆镜或删去次要运动，不以“复合运镜”绕过限制。
8. 经过门、镜面和狭窄通道时核对轨迹可达、灯具穿帮、摄影反射和参考图支持程度。摄影机不能穿过墙体、人体和实体道具。空间无法确认时缩小路径，不假装已有完整场景数据。
9. 移焦须明确近远主体、先后清晰状态与触发动作。浅景深跟拍保留跟焦余量，避免同一短动作同时要求极浅景深、多次跨景深移焦和复杂快速位移。

## 交付

独立运镜单使用“镜号｜叙事目的｜演员路径｜摄影起点→终点｜主运动与速度感｜焦点｜起幅→落幅｜声音与切点｜可行性”。起落幅写真实画面，不只写运动名称；必要替代方案说明收益与代价。

已有分镜或 JSON 时写回既有动态提示词字段，保留对白、资产 ID、情节、时长和 schema。首帧只描述起幅。30 秒连续模式总时长进入既有时长字段，正文不写逐镜秒数；其他模式按用户要求。只交付指定阶段，不能把方案完成报为视频执行成功。

需要长镜头拆分、推拉变焦辨析或失败降级时，读取 [运镜推演与最小修正](references/movement-review.md)。

## 复核

核对信息是否增加、轨迹能否到达、人物为何换位、焦点为何改变、起落幅能否相接及关键动作能否看清。先删无动机运动，再改路径、速度感和构图，最后才考虑复杂设备。
