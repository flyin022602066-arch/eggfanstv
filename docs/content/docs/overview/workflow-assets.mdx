# 工作流资产库

## 按工作流分类

个人资产库默认按工作流名称分组。顶部「按工作流分类」可选择一个工作流，或查看未关联工作流的「公共资产」。已有资产会根据画布节点的资产 ID、原始资源及保存记录识别归属；工作流改名后分类名称同步更新，同名工作流仍独立保存。一个素材被多个工作流使用时，可在对应工作流下分别找到。

## 手动保存文本

选中文本节点后，点击工具栏「保存文本」，将正文保存到个人资产库并关联当前工作流。修改正文后再次点击会更新同一个资产，不重复创建。没有点击保存的文本不会自动加入个人资产库。

也可以在个人资产库点击「新建 → 保存文本」，填写标题、正文并确认保存。先选择工作流再新建时，文本归入该工作流；在「全部工作流」或「公共资产」下新建则归入公共资产。文本可从资产库再次引用到画布。

## 项目角色、场景和道具生图

「角色与资产」顶部可选择全部集数、具体某集或未关联集数。归属来自已确认资产的章节提取记录及镜头实际绑定，包含引用旧版本的镜头；同一资产跨集复用时，在对应各集均可查看，不复制资产。没有来源或镜头关联的素材保留在「未关联集数」，不会丢失。每个范围内按角色、场景、道具、素材和其他分别显示，卡片下方标明关联集数，悬停可查看全部归属。集数可与分类、文件夹、名称搜索组合筛选。

在「项目制作 → 角色与资产」确认剧情提取的资产后，保存的是文字设定，需要另外生成图片。角色卡点击「生成角色三视图」；场景和道具卡点击「生成场景图」「生成道具图」。弹窗中可选择图片模型、画质、尺寸并调整提示词，自动应用项目画风。

缺少道具时，可在「角色与资产」或「分镜制作 → 镜头资产」点击「新增道具」，填写名称、所属集数、别名和外观设定。名称或别名应与分镜中的用词对应。同名或同别名的现有道具直接复用，不重复创建；待确认道具会先完成确认。点击「保存并配置道具图」继续选择图片模型和提示词，确认「开始生成」才会提交生图。已绑定但缺图的道具可点击镜头资产卡片的加号直接补图。

道具图片完成后点击「补齐本章资产」，按镜头画面与动作中的名称、别名或资产引用补齐绑定，即使旧拆解结果的道具清单漏写也能识别。仅对白或接戏说明中提到的道具不会补绑，也不会将道具继承到本章其他镜头。补图保留原道具 ID，已有有效版本引用继续保留。

顶部「统一生图设置」按角色、场景、道具分别设置模型、画质、尺寸和通用补充要求，适用于各项目的单张及批量生图。场景可以使用与角色、道具不同的模型。单张弹窗中的这些参数也会自动记忆，重启后继续使用；当前资产的专属提示词不会覆盖其他资产的原始设定。尚未设置时优先使用项目图片模型；已保存模型不可用时会提示重新选择。

「一键批量生成角色图」「一键批量生成场景图」「一键批量生成道具图」跟随顶部集数范围，覆盖该范围所有目录与分页中的已确认资产，不受名称搜索影响；「全部集数」处理全项目。默认只补缺图，并跳过正在排队或生成的资产；关闭「仅生成缺图资产」可为已有图片生成新版本。确认面板显示范围、本类模型及任务数量，提交后显示进度、成功数量和失败资产原因，已入队任务继续在后台执行。

人物提取与角色生图统一使用固定构图：同一张设定图左侧为独立头部特写，右侧为正面、右侧面、背面身体三视图。身体三视图采用自然裁切，仅展示颈部以下至脚底，不包含头部；各视角保持同一服装、体型、道具和比例。已有角色重新生图也会应用此规则，补充要求不会覆盖固定构图。历史图片保留，需要重新生成才会变为新构图。

提交后任务在后台执行，离开页面或重新打开软件不会取消任务。生成完成后图片自动绑定到原资产的新版本，保留原始设定与旧版本。之后在「分镜制作 → 资产」中选择对应资产作为镜头参考。已有图片可点击「重新生成资产图」生成新版本。

项目分镜预览、历史缩略图、资产卡和下载均通过桌面鉴权读取原始资源，无需重新生成已有图片。

角色卡预览会显示原图的实际像素尺寸。点击图片或「查看原图」可打开大图，切换「适应窗口」「100% 原尺寸」或放大、缩小；原尺寸下可滚动查看细节，关闭大图后回到角色卡。查看时使用同一份原始图片，不改变下载尺寸。

## 镜头视频声音

章节拆镜和保存分镜时会读取本项目完整资产目录，按已有资产 ID、角色名称与别名、镜头中出现的场景和道具名称绑定资产版本。不会把其他项目或历史生成视频当作角色参考。重名资产会提示手动选择；项目镜头绑定不限制资产总数，也不截断引用。提交视频时按当前模型分别校验参考图片、视频和音频：模型名称含 SD2.5（包含 sd-2.5、seedance-2.5 等写法）的图片上限统一为 30 张，SD2.0 为 10 张，其他视频模型原有不足 10 张的正数上限自动修正到 10 张。旧配置中的 6 张限制自动修正，无需重新拉取模型；明确禁用图片参考的其他模型仍保持禁用。音频、视频数量及各渠道提交格式保持各自协议规则。

点击生成时会检查并补齐缺失绑定；已有角色引用也会继续检查场景和道具，不会直接跳过。连续同场景镜头沿用已确定的场景，明确转场后切换或停止继承；道具仅根据本镜画面、动作和结构化道具清单匹配，不继承上一镜的道具，不把对白或接戏说明中提到的资产当作实际出镜资产。已有手动绑定保留原版本。

「镜头资产 → 按规则匹配」检查当前镜头，「补齐本章资产」检查本章所有镜头，重复执行不重复绑定，也不提交生成任务。正在生成的镜头会跳过，任务结束后可再次补齐。无法确定场景时提示手动选择；绑定资产缺少图片时停止生成，提示先生成或上传参考图。

项目镜头视频的 Eggfans Seedance 使用 URL 参考方式：后端在生成前将本地参考图上传 Uguu，并将公网 URL 放入当前渠道规定的图片参数。缓存链接会检查有效期和可访问性，失效后从本地原件重新上传并更新记录。独立画布的 URI/URL 选择，以及要求平台 URI 的其他专用渠道，继续按各自协议执行。

佳速镜头视频与画布共用人脸处理控件和提交逻辑。在「生成设置」中选择服务端默认、保持原图、轻度处理或素描处理，选择会自动记忆。dola 模型和 `sd-2.5-j2-V` 均支持本地自动人脸遮罩及 50%、60%、75% 网格密度；开启后先读取原图、识别人脸、生成独立处理图，再上传图床并向视频模型提交处理图 URL，原图保留，失败时不提交视频任务。画布节点还可预览和手动框选。`sd-2.5-j2-V` 上游不接受 `face` 字段，默认或关闭时不发送该字段；该模型的人脸处理使用本地遮罩，历史轻度或素描设置须切回服务端默认。dola 的服务端人脸处理参数保持原样。

支持同步音频的内置 Seedance 模型默认开启声音，新建画布视频节点和镜头视频任务均采用此默认值。在「镜头视频 → 生成设置」中使用「生成声音」控制同步音频，折叠栏会显示「有声」或「无声」。该选项记住上次选择；切换时保留尚未保存的提示词、镜头时长和模型。模型不支持同步音频时开关禁用，提交时保持关闭。

声音选项作用于新提交的任务。已生成的无声视频没有音轨，开启后需要重新生成，才能取得模型输出的音频。

## 30 秒连续分镜

「生成章节分镜」的分镜技能按项目自动保存。第一集选择后，后续集数、关闭弹窗再打开及重启软件均沿用同一组合；修改后成为该项目新的默认选择，清空则保持不选技能。不同项目互不影响，最多选择四个技能。文本模型与拆解模式继续使用各自已保存的项目设置。

镜头视频的「最终提交提示词」显示实际提交全文、总字符数，以及镜头与表演、资产与声音、技能规则各部分的字符数。计数采用 Unicode 字符，包含标点、空白与自动补充内容。内置 Seedance / SD 2.5 提示词上限为 15000 字符，旧版 8000 字符配置会自动修正；超过上限时提示精简，不截断对白、时间轴或资产引用。

角色魅力、世界观美术、AI 演员微表情三个内置技能在视频生成时使用专用的精简规则，完整技能仍用于 Agent 与文本创作；自定义技能包也可提供 `references/video-generation.md` 作为视频生成规则，没有此文件时沿用原上下文。视频提交会去除已包含的重复动作，并按说话人及完整台词逐条核对对白字段；角色名尖括号、引号样式、空白和说话前的简短表演标注不会导致台词再次附加。正文缺少的台词仍保留，未绑定角色的旁白也会提交；不会截断原有脚本、对白或资产。补充接戏、镜头语言和排除内容继续保留。选择技能与展开预览只读取本地规则，不调用付费模型。

在「章节 → 生成到分镜制作 → 分镜拆解模式」选择「30 秒连续分镜（2.5 视频模型）」。每个分镜对应一次完整的 30 秒生成单元，内部按「整体设定 → 镜头1、镜头2…… → 结尾约束」组织；每镜写起幅、落幅、单一运镜、动作和对应声音，不写逐镜秒数、时间码或阶段。首帧提示词只描述开始时刻。整章按剧情拆成足量单元，不将整章压缩为一个短片。模式按项目记忆，常规精细分镜仍可选择。

拆解首先按实际发声量安排表演。一个 30 秒单元内的所有说话人共用对白预算：单人独白约 25～45 字、两人对话总量约 40～60 字、快速问答约 60～70 字，按每分钟 150～170 字及自然接话停顿评估。旁白、画外音同样计入。对白密集时，在完整句或完整话轮处顺延到后续生成单元，保留原文、说话人与顺序，不加速硬塞或截断半句话。约 800～1000 字原文仅适合作为叙述及可并行动作为主的剧情容量参考，不能用于强行规定每段篇幅。少对白处用符合原剧情的表演、空间变化和环境细节充实，避免无意义等待。

「资产与声音」以 600 字符以内为精简目标，保留本段实际资产映射、声音样本和必要声线特征，避免再抄镜头里已有的对白。此数字包含参考说明，不等于实际可念的台词量，也不限制整段提示词长度；资产多时不会为凑字数删除绑定。视频提示词已有完整镜头序列时，不再叠加辅助动作字段里的另一套镜头序列，即使两者措辞不同；提示词缺少的对白仍由对白字段补齐。对白节奏规则在首次拆解请求中发送，优先于技能的篇幅和数量建议；已有分镜不会因更新自动改变，需要重新拆解或手动重分配对白。

「镜头与表演」使用 `videoMotionPrompt` 的完整导演脚本，依据所选技能展开摄影、动作、微表情、空间变化、对应声音与接戏，可以按剧情需要超过 1000 字。600 字符目标只作用于参考附录，少对白也不代表缩减导演描写；不以字数硬门槛验收或补写剧情。每个 30 秒生成单元的内部镜头从「镜头1」重新编号，独立于顶层分镜序号。首次请求在资产资料后明确完整导演要求与 JSON 合同，一次完成分镜制作。

「已保存分镜的格式检查」只提示已存脚本的编号、起落幅或时间码问题，不是额外的生成步骤；不会自动改写或再次调用模型。旧分镜需要调整时，可手动编辑，或重新拆解并确认替换。

生成请求要求每个单元明确声明场景资产、实际出镜人物和可见道具。同一地点逐镜重复绑定场景，转场更换资产，保留人物站位、持物手和道具状态的接戏信息。已确认但尚未生图的场景、道具也会进入资产白名单；实际视频生成仍需具备参考图片。

镜头视频保留分镜计划时长，不会因切换模型自动缩短。具体渠道和模型不支持 30 秒时会提示并阻止提交，需要选择支持该时长的模型或手动调整时长。

章节重新拆解只在新分镜及全部资产引用保存成功后整体替换旧分镜。任务生成成功但保存失败时显示「新结果待保存」，保留旧分镜与已生成结果；点击「应用已生成分镜」并确认替换可直接保存，不会重新调用模型。重新打开章节也会检查并恢复尚未应用的已完成结果，已保存的结果不会重复写入。

## 导出与导入

本地桌面版和本地开发版的视频生成完成后，先将上游原始文件保存到本地资源库，再自动复制到 `output/videos/video-资源ID.mp4`（其他视频格式保留实际扩展名）。采用项目根目录 `.local` 数据布局时，`output` 位于项目根目录；自定义到其他位置的数据目录则使用该数据目录下的 `output`。副本保留原始字节，不使用播放预览转码文件，不会压缩视频。导出失败时保留资源库原件并记录错误，不会因此重新提交生成；也可使用界面下载原件。

镜头视频的「旧版本」表示镜头脚本或参考资产发生过修改，与临时链接过期无关。历史视频仍可播放和下载，生成新版本后可继续对比；不会因为脚本更新删除原件。

点击「按工作流导出」，选择工作流并确认「导出资产包」。ZIP 包包含关联图片、视频、音频的原始文件和当前画布文本，不受当前类型筛选或分页影响。文本同时提供独立 TXT 文件；导出当前未手动保存的文本不会将其自动加入个人资产库。缺少原始媒体时会报告具体素材，避免导出不完整包。

点击「导入资产包」选择 ZIP。导入先检查清单与文件完整性，再将原始文件重新登记到当前设备资源库，并建立独立的工作流分类。重复导入同名工作流不会与已有项目混在一起；导入记录保留原工作流名称，清除另一设备的画布和文件地址关联。

资产包用于迁移素材，不包含画布布局和节点连线。迁移画布结构请使用画布自身的导入导出功能。右上角「更多资产操作 → 导出当前筛选资产」可只导出当前筛选结果。

桌面版超过 32MB 的资产包按 1MB 分块保存，单包上限 8GB；完整写入后才替换目标文件。取消、保存失败或退出软件时会清理未完成的临时文件。打包和导入仍需要可用内存，素材很多时可以分工作流操作。
