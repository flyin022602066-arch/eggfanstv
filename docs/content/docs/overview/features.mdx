# 功能清单

## 项目工作台读取

项目、章节索引与当前章节工作区的读取允许较慢的本地响应，并对连接中断、读取超时和可重试的服务错误最多自动重试两次。后台刷新暂时失败时，保留当前已加载的分镜、选择与编辑状态，显示刷新失败提示并提供「重试读取」；初次加载失败时提供独立的重试入口，不将临时读取失败误报为项目删除或权限不足。切换章节独立加载对应数据，不用上一章的镜头填充失败的章节；真实的未登录、无权限和资源不存在错误仍会阻止显示相应内容。

## 项目画风

创建项目时可在「项目画风 → 风格中心」选择推荐规范，或用「组合画风」分别设置题材世界、叙事气质、视觉媒介和角色造型。题材包含仙侠、都市、历史、悬疑、科幻、田园、末世废土、东方武侠、民国年代与东方神话；每类题材都有真人和三维推荐版本。媒介支持真人实拍、3D 国漫、3D 写实 CG、3D 卡通、二维国漫、二维赛璐璐和水墨，角色造型按媒介匹配。

组合生成的完整规范包含色彩光线、服装材质、环境、运动与一致性规则，可继续编辑并保存到「我的风格」，也可从最近使用中再次应用。项目保存完整画风快照，角色、场景、道具生图与视频生成沿用同一规范；已有项目快照不会自动被新预设覆盖。二维和三维规范示意封面仅说明媒介，不代表模型实际成片效果。

## 工作流资产库

角色资产采用左侧角色列表、右侧造型卡片的工作区，沿用集数、类别和文件夹筛选。每个角色共用基础身份与声音，服装、年龄、伤态或形态分别建组，同一造型的重绘收入图片历史。新建造型仅需名称与差异，可展开高级设定；上传、素材库选图和生成的新图需「确认选用」，不会自动取代旧定稿或镜头绑定。基础人脸与默认出镜造型分别管理，每套造型独立显示任务状态。

默认每组紧凑展示一项，不让空白历史版本占位；独立待补图造型保留卡片，历史版本可展开预览、下载原图、精确用于当前镜头或删除。删除只归档该版本并保留原图；已绑定镜头、画布或活动任务的版本需先解除引用，最后一个版本通过移除整个角色资产处理。AI 外观说明需支持看图的文本模型，只填入草稿供核对；不会自动提交媒体任务。

分镜中的「手动绑定角色」支持绑定尚未生成参考图的项目角色，并显示「缺参考图 · 已手动绑定」；可在同一卡片补图、上传或选用素材库图片，确认具体版本后再生成视频。项目中遗漏的角色可通过「新增角色」保存到角色库并绑定当前镜头；已有同名或同别名角色会提示复用。手动绑定会锁定选择，自动识别与补齐不会覆盖；新增成功但绑定失败时保留角色并提示手动恢复，避免重复创建。

自动补齐会结合本镜画面与章节原文核对实际出镜人物，不把模型返回的角色数组当作完整名单；普通叙述中的「声音」不会截掉后续人物动作，单纯提及、电话声音与画外音仍不会自动成为出镜人物。逐镜规划会将富文本正文恢复成完整句和完整话轮的定位行，再由模型按剧情安排生成单元，不因原稿只有一个段落而只能拆出一段。

章节提取保留同一角色的多套 `looks`，确认时创建独立造型版本。跨章节按角色身份与造型共同去重，同名角色的新服装仍进入候选。已有合并在 `clothing` 中的编号造型或明确换装说明，可用「从当前设定拆分多套造型」直接拆分；每套只使用自己的服装提示词并独立补图，不把旧服装图片直接当作新造型成品。

多形态生成先建立基础造型图片，后续造型携带基础版原图走对应模型的参考编辑能力，锁定脸型、五官和人物身份，再修改服装、姿态与道具；只有剧本或用户明确指定的头部变化才局部调整，其余面部特征保留。生成弹窗展示实际使用的基础参考，后端核对同角色、同用户及图片可用状态，缺少基础图或不支持参考编辑时不降级为文生图。批量补图先等待基础图完成，再提交其他形态；基础图失败时停止后续提交。首次基础图仍支持男主、女主人脸预设，基础身份建立后新预设不会替换后续造型的面孔。已有图片和镜头绑定不自动修改，历史漂移的造型需主动重绘。

「镜头资产」内的角色卡提供识别本镜、识别本章、仅待确认及手动选择/锁定，与场景和道具在同一区域核对，不再另占右侧长栏。识别由用户点击后调用文本模型，结合原文、镜头和同场景接戏选择定稿；信息不足保留为待确认，变身或同人不同年龄同框提示拆镜头。生成中镜头与锁定项跳过。真正改稿后自动选择需重新确认；重绘不会替换旧镜头图片。视频仍由用户主动生成，提交时记录精确角色版本和图片，缺图或选择冲突会阻止提交。

角色卡的造型版本下拉可手动选择任意有图版本，包括未定稿或历史版本；选择后只锁定当前镜头，预览和生成参考图使用同一版本。「管理造型」默认打开本镜已绑定版本，也可查看其他版本并点击「用于当前镜头并锁定」。定稿、默认造型只影响自动识别，不会替换已有镜头；单纯自动补齐提示词中的资产引用不算用户改稿，不会禁用版本选择。手动修改脚本后仍需先保存，生成中镜头不可更换绑定。

人物造型目录和出镜角色识别仅匹配角色，场景或道具的同名、共享别名不会阻断角色面板。场景与道具优先按完整名称匹配，道具的明确资产绑定优先于宽泛别名；不同资产共用「手机」等别名时，沿用镜头已绑定的资产 ID，不将其当作同一资产的多个版本。确有未确定的同名资产时，在镜头资产列表按名称和 ID 绑定对应资产。

个人资产库按工作流名称自动分组，可按项目筛选；文本节点提供「保存文本」入口，再次保存更新原资产。支持一键导出工作流内全部原始媒体及当前文本，并将资产包导入为独立分类，重新登记本机资源。操作说明见 [工作流资产库](./workflow-assets)。

项目角色、场景和道具生成图片后同步到素材库，复用原始图片资源，不额外压缩或重复保存。资产尚无图片时，也可在生图弹窗点击「直接使用素材库图片」完成绑定，不需要先生成；「选择生图参考」则将选中原图用于参考生成。角色「造型与版本」也提供素材库选图入口；后续造型生成仍以基础版图片锁定身份，额外参考用于服装与构图。

章节分镜支持常规精细拆镜和按项目记忆的「30 秒连续分镜」模式，每个生成单元包含有序镜头、对白和场景道具清单。镜头生成前会补齐已有资产的绑定；同场景逐镜绑定，道具按本镜可见内容匹配，也可使用「补齐本章资产」检查已有章节。场景与道具沿用标准名称及明确别名；同一镜头的多个地点分别匹配，不用室内场景替代缺失的外景。「补齐本章资产」会把缺少的场景和道具整理为本章待确认资产，镜头面板也可点击缺项或「新增场景 / 新增道具」补建。确认并补充参考图后再次补齐即可绑定，检查和补建本身不提交生图任务。模型不支持计划时长时会阻止提交，避免自动缩短视频。

章节道具按跨镜复用和剧情重要性筛选。普通物品仅出现一次、只作生活动作或背景点缀时，留在场景与动作描述中；同一物品在两个及以上不同镜头清晰可见且需要保持一致时，才单独提取。剧情关键线索、信物、特殊装置和可见系统界面即使只出现一次也保留。已有分镜随提取请求提供可见性依据；尚无分镜时按正文判断，不虚构重复出镜。筛选只影响新候选，不删除已确认或手动新增的资产。

系统流小说中的可见属性面板、状态栏与系统界面作为道具提取，同一系统共用一份面板设计；每镜文字、数值及提示音仍按原文变化，不创建“系统”人物。提取结果会依据原文明确的面板或连续状态字段补充漏提界面；纯声音播报不自动创造面板。已有章节可在「提取角色、场景与道具」中选择「仅补提系统道具」，从当前正文补入待确认列表；确认后沿用道具生图及「补齐本章资产」流程。补提本身不调用模型，生成图片仍由用户主动提交。

界面道具检测支持中文括号、半角与全角方括号，也支持无括号的连续宿主属性列表；列表需有宿主或明确系统上下文，普通人物资料表不会自动变成系统道具。检测提示、提取结果补全与任务刷新取回使用相同规则，不改写原文括号、文字或数值。

分镜写入及视频提示词整理时会核对资产引用。仅当错误 ID 的素材定义或参考清单名称与项目中的唯一角色、场景或道具完全匹配时修复 ID，已存在的真实 ID 及手动绑定版本保持不变。无法确认或存在重名时，在「最终提交提示词」中显示引用 ID 与上下文，可替换为已绑定资产或移除多余引用；保存脚本后保留修复结果。未绑定资产仍需先补齐绑定，缺少参考图仍需生成或上传，不会悄悄丢图提交。

章节分镜的「已生成」以实际写入的镜头为准，不把上游文本任务成功等同于分镜已保存。模型返回的场景 ID 不属于本项目时，依据场景名称及明确别名核对唯一资产；真实 ID 保持不变，重名要求人工核对，未建场景保留名称供后续补齐，不丢弃整章脚本。写入失败会保留「核对后写入」入口，继续使用原任务结果，不重复生成；资产重名时可在确认窗选择正确角色、场景或道具后继续，写入错误会留在入口旁供重试；成功保存后进入对应章节的分镜制作。

系统面板资产图只作为外框、配色、材质和布局模板，生图时姓名、形态、数值和进度区域留空；原文证据仍保存在资产描述中。后续分镜使用当镜的系统原文更新显示内容，未给出的数值留空，不照抄参考图或其他章节。已有带固定数值的图片不会自动修改，可重新生成模板；视频提交提示词也会声明不得继承参考图中的旧状态。模型对可读文字与数值的还原仍需核对。

章节资产提取和分镜生成均可选择「系统面板」或「拟人化系统」，按项目保存，后续各集与重启后沿用。面板模式保留界面道具流程；拟人化模式可设置角色名称、动物或精灵等形象及声音，提取为角色资产，确认后生成形象图，由同一角色承接原文系统台词与当镜状态，不凭空增加对白，也不自动绑定旧面板。拟人化系统使用适合其造型的完整正、侧、背视参考图，普通人物仍沿用头部特写与身体三视图。仅补提系统角色不调用模型，生成形象图仍需主动提交。修改模式只影响后续操作，不自动改写已有资产、分镜或视频；生成任务保存提交时设定，刷新取回时不受后续切换影响。

基础拆解规则按自然表演规划对白：以一个 30 秒生成单元内全部镜头合计为参考，单人情绪独白约 25～45 字、两人对话合计约 40～60 字、争吵或快速问答约 60～70 字；超过 80 字时重新评估节奏，不作为硬性上限或裁剪阈值。中文语速约每分钟 150～170 字，话轮之间预留 0.5～1.5 秒自然停顿；常规短镜头按实际时长折算。模型在首次拆解时保留原文台词、说话人和顺序：略超但能自然完成则完整保留，放不下则在完整句或完整话轮边界调整相邻分镜，将后续对白及必要动作顺延，不截断半句话、不漏词、不重复。少对白时补充服务原剧情的环境、微表情与互动，密集对白时使用有动机的正反打、特写和反应镜头，不靠加速、无意义等待或虚构剧情凑时长。数值只用于内部节奏判断，不在 30 秒模式正文中新增时间码；已有分镜和生成结果不会被程序自动截断或改写。

30 秒模式以约 800–1000 字的原剧本剧情作为单段容量参考，并按因果、动作、对白密度和真实表演节奏调整；这不是视频提示词的长度目标。视频提示词按完整导演脚本规则编写，只遵守所选模型的实际 API 上限。提示词按「整体设定 → 镜头1 / 镜头2 / 镜头3 … → 结尾约束」组织，镜头数量按剧情自然决定。每镜仅一种运镜，写明「起幅 → 落幅」、主体动作表情、空间变化及对应音效或原文台词。正文不写绝对秒数、时间码或逐镜时长；总时长仍为 30 秒并作为视频参数提交。素材映射沿用已绑定的资产，画风遵循项目设置；结尾统一要求画质、面部与服装稳定、无水印和防重复人物。短暂喘息、眨眼等与事件并行，不用停顿硬凑时长；内容不足时忠实原文优先。生成结果仅提示秒数、镜头结构或格式问题，保留模型原始结果，不自动重写或再次提交生成。已有分镜不会随规则更新而改写。

30 秒连续分镜先按整集 90～180 秒统筹，通常拆为 3～6 个生成单元，再在每个单元内设计切镜、正反打和运镜。段内镜头变化不增加视频任务，不将对白参考字数作为无限拆段依据。普通小说叙述优先转为动作、表情与环境，只为不可见信息保留必要短旁白；每段分别核算对白、旁白与表演空间，不能用相邻段落的空闲抵消局部超时。原文台词保持完整和先后顺序；确实无法兼顾时在叙事意图中说明冲突，供用户核对，不静默删词或加速。

## Suno 音乐导演台

侧栏「音乐导演台」进入 `/music`，沿用已配置的 Eggfans 自定义渠道、Key 和请求头，音乐模型单独选择，不改变图像、视频或语音合成的默认模型。支持灵感描述、自定义歌词、纯音乐、续写、局部补段、翻唱、Persona、混搭、分轨及音频工具；参数按 Suno 原生合同校验，默认地址为 `https://api.eggfans.com`。

工作台包含参数区、音轨试听与制作队列，支持本地参考音频、真实波形、定位播放、循环及区间回填。草稿、任务 ID 和成品记录按工作区本地保存；重开继续查询原任务，不重复生成。所有完成音轨分别存入本地素材库，可再次引用或导出，查询中断与素材保存失败不会误判生成失败。版权上传需确认文档标注的 30 积分费用。完整参数和验证边界见 [Suno 音乐导演台](../backend/suno-music)。

画布文本和音频节点可直接打开音乐导演台。已连接的文本可写入歌词，Suno 曲目可带着原有 clip/task ID 继续创作；生成曲目和歌词也可分别回写到画布节点。草稿按画布项目及节点隔离，避免不同创作串用参数。

音乐导演台新增「MV 制作」板块，可选择曲库歌曲、已配置且声明支持音频参考的视频模型、参考图片、画面提示词、比例和分辨率。按模型能力裁取歌曲片段作为音频参考，视频任务沿用现有渠道提交、查询、结果预览与本地持久化流程；不符合音频参考能力的模型不会出现在列表中，必需参考图会在提交前校验。当前每次生成一个视频片段，尚不包含整首歌曲自动分段、批量计费确认和片段拼接。

## 画布参考模板

图片节点提供「参考模板」入口，可单张导入姿势、服装和角色图片，按名称、标签、视角筛选，收藏或保存组合复用。应用后图片进入真实参考链路，用途说明按实际图片编号提交，保留主体提示词与模型选择；应用不会启动生成。模板目录按账号本机保存，引用只进入主动应用的项目。使用与保存边界见 [画布参考模板](./canvas-reference-templates)。

## 图片节点本地上传

空图片节点中央和节点快捷工具栏提供「上传本地图片」。已有图片可在工具栏点击「替换图片」，选择本机文件直接保存到当前工作区资源库，并保持节点名称、位置与连线。图片按原始比例显示，替换失败时恢复原图。简单模式与专业模式均可使用；只读、锁定或正在生成的节点不可替换。此入口不上传公网图床，视频生成所需的图床链接仍在生成时按渠道准备。

## 画布视频播放

空视频节点中央和快捷工具栏提供「上传本地视频」，已有视频可在工具栏点击「替换视频」。本地文件保存到工作区资源库并保留节点名称、位置与连线；上传失败恢复原视频，重开后可继续引用。简单模式与专业模式均可使用，只读、锁定或正在生成的节点不可替换。作为模型参考时沿用所选渠道的自动 Uguu 直链准备流程，过期链接重新上传。

画布视频节点和首帧生成优先使用已就绪的 H.264 兼容副本，避免 H.265 原片在浏览器内只有声音或无法显示画面。播放副本和原片分别缓存，下载及模型参考仍保留原素材。副本准备中显示进度提示，读取或解码失败显示原因并提供「重试播放」；点击播放后若被浏览器阻止，则显示手动播放控件。

点击 AI 生成的视频节点可继续编辑提示词、模型与生成参数，再次点击「生成」使用当前输入提交新任务。清空提示词草稿后仍可重新打开编辑面板；草稿编辑保留已有视频和上一次生成的提示词记录。空白提示词不能提交，已有任务进行中时不能重复生成。

## 中转网关视频协议

模型配置可使用 `Wan Task Gateway` 插件接入万相 3.0 与 HappyHorse 视频模型，按协议完成异步创建、轮询和结果解析。万相 3.0 提供 2–30 秒时长，HappyHorse 使用独立的时长和画幅选项；模型 ID 以所用渠道的实际目录为准。参数与素材格式见插件的接口文档。

已安装且启用对应协议插件时，已知模型名可自动补全缺失的请求协议；用户明确选择的协议优先。渠道适配预设按精确主机名匹配，仅修正目标网关的参数画像，不改写 Eggfans、佳速或 Mints 的地址、模型目录和协议。错误提示区分模型未授权、上游不可用与接口路径错误，避免把上游 404 一律解释为模型名错误。

## Eggfans Seedance 私域参考库

Eggfans 渠道的 Seedance 模型使用原生任务协议，默认地址为 `https://api.eggfans.com`。点击模型配置或资产页的「私域人像库」可管理素材组与图片、视频、音频资产，查看审核状态、复制资产 URI、绑定本地素材，并获取真人认证链接及认证后的素材组。视频任务页支持查询原生与 Volc 上游任务。

本地模式的模型配置提供独立「火山 URI 资产库」，按接入文档通过山河资产服务获取火山 URI。填写资产上传 Key 后，Seedance 参考图片自动经过 Uguu、素材组查找/创建、资产激活，再使用 URI 请求原视频渠道。「火山本地资产库」支持手动同步已有图片或上传新图片、查看记录及复制 URI。原图与 URI 默认一起归档到项目根目录 `asset-library/volc`，重启后自动恢复到软件资产库，可用 `@资产名称` 再次引用。已同步资产复用 URI，失败或结果不确定时不重复创建；SD2 始终使用 URL。

在生成前默认自动上传本地参考素材到 Uguu，再以 URL 创建私域资产，等待 Active 后仅提交 `asset://AssetId`。视频节点功能栏和视频设置中可切换「使用资产 URI」：开启时沿用私域资产库流程，关闭时跳过私域库并提交自动检查、必要时刷新后的公网 URL。已保存的绑定重开软件后复用；审核失败会停止 URI 模式生成。`@资产` 解析所得的参考媒体保留原顺序，`@图片N`、`@视频N`、`@音频N` 对应同类素材顺序。Seedance 2.5 的参考数量配置为 30 张图片、10 段视频和 10 段音频；该数量按接入要求配置，提供的文档未明确其余 2.5 专用限制。详细参数见 [HTTP API 合同](../backend/http-api)。

## EggFans SD2 视频渠道

「模型配置」内置独立的「EggFans SD2 视频」渠道，包含 `sd-2.5-A` 至 `sd-2.5-E`，无需联网拉取目录。点击「编辑」填写该渠道的 API Key；默认地址为 `https://vip.eggfans.asia`，地址与自定义请求头可修改。视频模型选择器会列出这五个模型，新增渠道不会替换已有模型目录、密钥或默认选择。

该渠道使用 `eggfans-sd2-video` 协议创建和轮询 `/v1/videos` 任务，支持整数 4–30 秒、固定 720p、首尾帧或多素材参考。图片上限为 30 张，B/D 为 9 张；视频、音频参考各最多 10 个。本地参考图片在生成时通过 Uguu 免费临时图床取得公网 HTTPS URL；视频和音频在未配置公开地址时也可自动上传 Uguu。原件保留在工作区，临时链接预计有效 3 小时；每次使用前检查链接，失效或临近过期时自动重新上传。SD2 只提交 URL，不上传私域素材库、不提交 `asset://`，与 Eggfans TV Seedance 的私域 URI 流程隔离。接口参数见插件的接口文档。

上传成功后，选中图片打开「节点信息」即可查看完整的 Uguu 临时 URL、预计失效时间并复制链接。上传状态保存在工作区，重开软件仍可查看；过期后隐藏复制入口，下次生成按需重新上传。

选择 SD2 的 `sd-2.5-A`、`sd-2.5-C` 后，在视频节点「视频设置 → 输出」中可切换“过人脸”。默认关闭，开启时向上游提交布尔参数 `native_face: true`。B、D、E 禁用开关且过滤旧节点遗留的开启参数；关闭时也省略字段。每个节点保留自己的选择，全局记住最后一次切换供新节点使用，重开软件后恢复；其他视频渠道不显示或提交此参数。

## Mints Seedance 渠道

独立的 [Mints Seedance 渠道](../backend/mints-seedance) 在视频生成节点自动完成 Uguu 上传、平台资产激活与 URI 绑定，支持参考图片、视频、音频和首尾帧。URI 与原素材关联保存在本地，重用时检查状态，失效链接自动重传，参数和缓存与其他渠道隔离。

## 极途 Gway 视频渠道

`dola-sd-2.5` 在视频节点可选择 1–30 秒，30 秒原样提交为 `duration: 30`；2.0 保留 1–15 秒，H3 固定 15 秒。更新内置能力后，已配置渠道会恢复新的时长上限，同时保留 URL、Key 和请求头。

模型配置内置独立「极途 Gway」渠道，默认使用极途 Gway 地址 `https://www.gway.dev`，从 `/pricing` 对应的 `/api/pricing?surface=plaza` 拉取视频模型目录。旧佳速默认地址自动迁移，Key、自定义请求头、模型选择和视频请求参数保留，其他渠道及自定义服务地址不受影响。模型不加入文本或图片选择器。2.5 支持 30 张参考图、10 段参考音频；H3 的参考视频总时长不能超过 15 秒。

该渠道创建 `/v1/video/generations`、查询 `/v1/videos/tasks/{task_id}`，从 `result_urls` 获取结果。素材自动转为公网 URL，和 Seedance 私域 URI、SD2 参数隔离。视频设置提供独立「人脸处理」，不会传入 SD2 的 `native_face`。首尾帧通过 `images[].type` 提交，使用首尾帧时不能同时参考音频。H3 输出固定 15 秒、2k。完整参数见佳速插件接口文档。

佳速 `dola-sd-2.5`、`dola-sd-2.0` 默认开启离线自动人脸遮罩。视频节点「人脸遮罩」支持多图预览、移动和缩放框、手动补框、切换网格/马赛克或关闭，调整随节点保存。预览不上传图床；开始生成时先保存处理副本，再准备有效公网 URL。原图保留，缓存副本可复用，链接失效时重传对应副本。自动识别失败时提示手动框选或关闭，未检出人脸时可手动补框。H3、Eggfans SD2 和 Seedance URI 流程不受佳速遮罩设置影响。

Eggfans SD2 渠道的 `sd-2.5-D` 也提供「人脸遮罩」，可在节点或视频高级设置开启「自动人脸遮罩」，默认关闭。启用后先本地识别并生成网格/马赛克副本，再上传图床，以副本 URL 提交视频；支持预览、手动调整和重复调用。D 的开关、框选记录和处理副本缓存与佳速独立保存，不改原图，不走 Seedance 私域 URI。本地遮罩与原生「过人脸」独立：原生开关开启且有参考图片、参考视频或首帧时才提交 `native_face: true`；仅文本、音频或尾帧时不提交。本地遮罩不会强制关闭原生开关。遮罩仅是参考图处理，不保证上游内容审核通过。

## 媒体导入与预览

视频导入不要求浏览器先解码成功，H.265 原文件也可直接保存到画布。能够读取的尺寸会在上传完成后补齐。画布优先直接播放原视频，无法解码时按需准备 H.264 预览，显示进度并复用已完成的预览；下载和素材引用仍保留原视频。预览处理失败时可以重新加载。在「问题诊断」中可以清理已完成的预览缓存，下次播放时按需重新准备。

Windows 安装包自带视频处理工具，无需另外安装 FFmpeg。预览转换一次只处理一个视频，并限制线程数和预览分辨率，避免同时转换多个素材占满电脑资源。

图片缓存读取失败时会重新下载资源；图片加载失败会显示「重新加载」，可以直接重试。普通鼠标滚轮以鼠标位置为中心缩放，触控板滚动和水平滚动保留平移行为。

## 接入自己的模型服务

在设置的「模型服务」中添加 OpenAI、Google Gemini、火山方舟或兼容服务，填写地址与 API Key 后读取模型目录。可以搜索、按用途筛选，也可以手动添加服务商提供的模型 ID。只有保存后才启用服务，取消不会留下未完成的服务。

每个模型可配置用途、协议与参数。重新读取目录保留已选模型和手动配置；目录里出现模型不等于已验证可生成。模型测试会提示供应商费用，并等待任务完成后显示结果，产物可在任务中心查看。连接或模型设置变化后需要重新测试。

## 内置 Agent 已退场

旧内置 Agent 已退场，由基于官方 pi SDK 的创作助手替代。

内置「小说拆解剧本」技能保留原著诊断、人物与全剧结构、分集大纲、正式剧本、质量检查和连续创作规则。可在 Agent 技能库启用或用 `@小说拆解剧本` 调用；画布中的明确小说拆解／改编请求会在技能已加入、启用且未超过技能数量上限时自动选用，并保留到后续对话。未指定阶段时先做原著诊断；分批原文未发送完毕时先整理材料。长篇文本通过 `canvas_read_text` 分页读取，正式文学剧本通过 `canvas_write_novel_script` 按集保存为普通文本节点，由程序统一排版集标题、时长、冲突、场次、时间地点、人物、动作、对白和集尾。分析与正文分开保存，后续可修订指定集。写入仍遵守画布权限、审批和快照校验，不会自动生成图片、视频或音乐。

技能库另提供五个面向30秒连续分镜的技能：「30秒大师运镜设计」「30秒人物表演与微表情」「30秒对白正反打与声音调度」「30秒动作调度与空间连续」「30秒悬念揭示与环境叙事」。在章节生成区的「分镜技能」中按剧情选择，最多同时使用四个，选择随项目记忆；画布创作助手也可主动选择或通过技能提及调用。这些技能按镜头顺序写明起幅、落幅、表演与声音，不固定章节单元数量或内部镜头数量，不使用正文时间码；遵循当前对白模式及平台输出合同，主导演脚本与资产声音附录的长度要求各自独立。原有技能保留，包含短时长限制的原技能继续显示对应标记。

## 画布保存保护与版本记录

创作对话中的文本任务完成后，会保留最终正文并同步任务结果。流式草稿与后端结果回填同时保存时，仅自动合并同一任务已确认的完成结果，保留后续消息；真正的编辑冲突仍需手动处理。重新打开对话时，误标失败但后台已成功的文本任务可恢复正文，结果同步失败不会要求重新生成。

旧页面或旧缓存不能覆盖云端新内容。每次内容保存核对服务端版本，发生冲突会停止该画布自动提交并保留本地草稿；平移、缩放和打开画布不触发整份内容保存。画布顶部显示保存状态，可保留草稿后加载云端最新版。

桌面本地工作区对保存版本冲突会读取最新版本号，并用当前编辑内容重试一次；重试仍失败时保留错误。普通保存与生成结果写入按画布串行处理，已经确认保存的生成结果不会被旧队列覆盖。视频节点优先复用有效的静态封面，缺失时补建，播放仍由用户手动触发。

「版本记录」在桌面右侧按日期展开历史树，小屏使用抽屉。点击版本进入独立只读预览，可以缩放查看或下载；返回当前画布后继续编辑。恢复历史会先保存本地草稿、备份当前云端内容，再创建一个新版本。历史只保存画布结构和媒体引用，不复制视频文件；普通快照最短间隔 5 分钟，每个画布保留最近 20 份，因此每次递增的版本号不一定都有快照。历史引用的媒体受到删除保护。本地绘图笔画不在云端历史中，草稿和历史导出不混入当前笔画。

此功能不提供多人实时协同或自动合并两个浏览器的完整画布；版本保护用于阻止静默覆盖。历史从升级后开始积累。

## 画布智能引用

节点提示词面板提供“智能引用”入口，支持 AutoLink 开关和“一键引用全文”。输入已连接素材的名称、标签或素材栏序号后，按 Tab 或点击光标旁的候选项插入引用；全文引用会批量转换匹配到的指代，没有可转换内容时按钮禁用。

## 批量创作表

批量创作表保留当前画布样式：顶栏拖动整表，表内控件不会打开“放入创作空间”遮罩。支持全局提示词覆盖各任务行、空槽点击/拖入上传、已有缩略图点击替换、参考图列拖拽重排，以及缩略图跨行跨列交换。连线到参考端口后会自动刷新任务行，“同步连线”仍可手动增量同步。全局提示词可手动编辑；批量创作表的读取结果会带上 `globalPrompt` 和按全局提示词计算的 `generationPreview`。

## 画布抓手与框选

## 章节资产提取与任务浏览

角色提取在模型请求前区分实际出镜者、仅发声者和仅被对白提及者；对白中的人名、关系和未来计划不直接构成出镜依据。明确展示的回忆画面、照片和屏幕影像按实际可见人物处理；纯画外音及电话另一端保留原文台词与说话人，不自动生成其人物形象。拟人化系统仍遵循项目已选择的表现模式。此规则随服务端受保护上下文注入，保存的旧模板及个人追加或改写也会收到该规则。

分镜只声明实际可见角色。自动补绑在姓名兜底匹配时排除明确的对白与声音片段；显式空出镜名单不会因台词中出现姓名重新补入角色。点击「补齐本章资产」时，会重新核对并移除缺少出镜依据的自动或规则绑定，同时清理对应的旧生成资产附录；手动、锁定及来源不明的既有绑定继续保留，不自动删除已确认人物资产或改写对白正文。

画布视频默认显示静态封面，点击播放按钮后才开始播放。鼠标悬停及操作其他节点不会启动预览，已暂停的视频也不会因其他节点更新而恢复播放。

剧情章节支持一次提取角色、场景与道具，分别写入角色、环境和道具待确认资产。输出必须包含三类数组；无人章节可以只产生场景或道具，不把缺失字段当作提取成功。

场景和道具出图后，可从资产卡片或资产预览点击“编辑提示词并重绘”。弹窗提供可直接修改的本次生成提示词，提交使用修改后的文本，再追加同类资产通用补充要求和项目画风；清空提示词时不能提交，取消编辑不会创建生成任务。

章节资产优先使用完整响应；若模型正文的资产 JSON 中途截断，任务沿用原渠道、模型、提示词和已接收正文自动续接一次。续接校验断点，再校验三类资产的完整结构，全部通过才回填；不从头重做、不无限重试。原始文本保存在任务中，续接仍不完整或请求失败时显示原因，不保存半成品资产。普通格式错误和明确的上游拒绝不会触发续接。

章节资产 JSON 的字段名或字符串值中若混入非法裸换行、回车或制表符，会在本地拼接断行后重新校验，不额外调用模型。合法的转义换行、引号和反斜杠保持原样，任务草稿保留收到的原始文本。仍然缺字段、截断或包含其他格式错误的结果不会当作完整资产回填。

任务详情只读取任务与日志，不因打开详情写入画布。视频任务列表和网格优先展示已有封面；没有封面时，在进入视口后提取首帧缩略图。

## AI 提示词优化器

提示词优化器是一个内置 AI 能力插件，用于把模糊的生图或生视频想法整理成可以直接使用的提示词。它复用宿主已经配置的文本模型和渠道，不在浏览器中保存或拼接第三方密钥。

### 使用入口

- 创作页 `/create` 的提示词输入框中，点击“优化”。
- 画布中的图片或视频节点提示词编辑器中，点击“优化”。

面板使用紧凑的聊天式交互，跟随当前输入框定位，支持拖动、边缘调整尺寸和窗口尺寸变化。打开与关闭不使用延迟动效，避免遮挡画布或让用户误以为请求卡住。

### 优化方式

| 方式 | 用途 |
| --- | --- |
| 扩展想法 | 从模糊想法补齐主体、场景、构图、光线、镜头等可执行细节。 |
| 精修已有提示词 | 尽量保留原意，只修正表达并补充必要细节。 |
| 强化风格 | 保留主体和动作，强化色彩、材质、光影与指定风格。 |
| 适配模型 | 按当前生成模型和协议调整提示词结构，避免使用未确认的参数语法。 |
| 结合参考 | 使用已连接的图片或文本补充外观、一致性、构图和关联关系。 |

面板底部可以单独选择优化所使用的文本模型；目标生成模型仍取当前图片或视频生成配置。两者职责不同：前者负责整理提示词，后者负责最终生成内容。

### 结果与安全边界

- 优化结果以结构化内容返回，包含正向提示词、规避项、修改说明、假设和可选备选版本。
- 结果可以继续编辑；只有点击“采用”才会回填当前输入框，并自动关闭面板。
- 请求支持流式反馈、取消和错误提示，不会在优化失败时覆盖原提示词。
- 参考素材只提交当前已连接且符合类型的内容；插件不自行访问素材库或后端密钥。

### 相关实现

- `web/src/lib/plugins/builtin/prompt-optimizer.ts`：插件清单、优化方式和模型适配策略。
- `web/src/components/canvas/canvas-prompt-optimizer-drawer.tsx`：聊天面板、拖动缩放和结果采用交互。
- `web/src/services/plugin-host.ts`：将插件文本请求接入宿主现有模型渠道。
- `web/src/pages/create/index.tsx`、`web/src/components/canvas/canvas-node-prompt-panel.tsx`：两个入口的接入。

## 画布外观

工作区侧栏底部可切换浅色或深色模式，选择会在本机保留。画布主题独立保存，不会随着工作区主题切换而改变；新建画布优先使用已保存的默认外观，没有默认值时跟随工作区主题。

底部工具栏的“画布外观”面板支持浅色、深色、自定义三种主题，以及点阵、线稿、空白三种网格。浅色画布使用比白色节点更沉的中性雾灰背景，深色画布使用比原深色节点更亮的中性灰背景，让画布底层与内容表面保持稳定区分，同时避免蓝灰背景与黑色工具浮层产生色温割裂。

首次进入自定义主题会继承当前浅色或深色基础界面；临时切换到固定主题后再返回自定义，会恢复之前的自定义颜色。界面样式沿用 BeefTV 的节点、工具浮层、文字、边框和交互状态，不开放这些元素的任意改色。

自定义主题还允许调整画布背景色、背景明亮度、网格颜色和网格强度。颜色输入支持三位或六位 HEX，可带或不带 `#`；形成合法色码后实时写入当前画布，编辑过程中不会被父级状态覆盖，关闭外观面板也不会撤销。选择新的画布背景色时明亮度自动归零，确保画布首先精确显示输入色；之后仍可沿 OKLCH 亮度轴单独调整。不提供背景透明度，避免画布底色与底层颜色混合后产生偏色。“网格强度”使用 `0%` 最淡、`100%` 最明显的方向，避免“透明度”命名歧义。

自定义外观可以应用到当前画布，也可以保存为当前浏览器、当前账号 scope 下的新建画布默认值。当前画布外观沿用画布项目的既有持久化和同步流程；浏览器默认值不跨设备同步。

### 当前能力

- **轨道与命令**：时间线支持添加、删除、拆分、移动、修剪片段等操作，全部通过统一命令状态机执行并进入 200 层历史记录，可撤销与重做；非法操作整批拒绝，不产生半应用状态。
- **分集视频库**：左侧媒体库仅显示视频，按项目集数和镜头顺序归类，未关联章节的视频单独显示。每集可「导入整集」，按镜头顺序追加到视频轨道末尾，后续集接在已导入内容之后；整次导入可一次撤销，不替换已有片段。图片、音频等原项目资产仍保留。
- **预设面板**：左侧“添加”分类提供 8 个内置片段/字幕插件，按分类分组接入同一插槽注册链，第三方插件可与内置面板共存。
- **权限与执行边界**：命令执行遵循失败关闭（fail-closed）策略，`timeline.command` 权限与全局 `plugins.run` 权限分开控制；未授权插件或命令不会被执行或回显。
- **语音转写（字幕）**：对时间线音视频发起转写任务，转写进度沿任务 SSE 回流，完成后生成字幕轨。
- **成片导出（渲染）**：发起渲染任务，由服务端 ffmpeg 按渲染计划输出成片；渲染成功后在项目概览的“剪辑成片”步骤卡呈现“已输出 N 个成片”，并作为该步骤完成度的判定依据。
- **智能成片**：AI 编辑助手默认进入导演模式，从当前时间线或项目媒体库选取素材，按剧情短剧、精彩混剪或自动判断生成完整组接方案。可设置自然/紧凑/高能节奏、目标时长、对白保护、字幕和背景音乐；设置按账号与项目保存。方案最多编排 120 个镜头，先预览叙事理由、镜头顺序、实际时长及提醒，再「应用并预览」或「应用并打开导出」。原始素材保留，可整批撤销。当前支持顺序组接、源内裁剪、原声、配乐和字幕，不包含自动变速、滤镜、转场或节拍检测。
- **素材理解与对白保护**：读取实际图片、裁剪后的视频采样画面、字幕和本地音量/静音检测结果；默认启用本地语音转写，根据真实对白规划切点并生成字幕，保留起句和尾部反应。没有转写或匹配字幕时，开启对白保护会保留所选视频的完整可用区间；目标时长不能强行截断台词。画面分析要求配置文本模型的参考图片能力，每次最多 24 张压缩画面、单视频最多 12 张；分析范围和失败项明确显示，不冒充已理解未采样内容。
- **对话微调与执行保护**：可切换回对话微调，对当前时间线做小范围调整，每次最多 8 条指令；不超过 3 条直接执行，多于 3 条先预览确认。导演方案及命令批全部预演成功后一次应用，一次撤销恢复整批。分析期间或确认前时间线变化会拒绝旧方案，锁定轨道不能覆盖。支持停止、进度提示和失败重试，导演方案的素材引用或时间范围无效时自动修正一次。
- **素材传输边界**：画面分析仅把本地压缩后的图片副本交给所选模型，不上传完整视频到图床；本地语音识别不请求云端转写，识别所得文字会随助手消息提交到所选模型。模型、渠道、Key 与自定义请求头沿用原配置。

### 运行环境要求

- 桌面本地模式可直接使用项目 `.local/tools/whisper` 中的 whisper.cpp CLI 与多语言 `ggml-base.bin`，无需常驻服务。已配置 `CANVAS_WHISPER_BASE_URL` 时优先使用原服务；服务端模式只使用显式配置的服务，不执行桌面二进制。转写临时文件位于数据目录 `cache/whisper`，任务结束后清理。
- 成片导出使用本机 FFmpeg。Windows 应用优先使用随包工具；开发或自部署环境可通过 `CANVAS_FFMPEG_PATH` 指定，未指定且无随包工具时在 PATH 中查找。
- AI 编辑助手需要可用的文本模型渠道；理解画面还需要上游实际支持图片输入，并在「看图能力设置」或模型配置的「能力与参数」填写参考图片数量、大小。未配置时可以操作时间线，但不能理解画面。

- `web/src/pages/projects/detail/editor.tsx`、`web/src/pages/projects/detail.tsx`：编辑器页面与路由入口。

- `web/src/stores/editor/editor-store.ts`：编辑器状态与快照持久化。
- `web/src/lib/plugins/editor-slot-registry.ts`、`web/src/lib/plugins/builtin/editor/`：插槽注册链与内置预设插件。
- `web/src/lib/plugins/plugin-permission-check.ts`：命令执行权限与失败关闭策略。
- `web/src/services/api/timeline-tasks.ts`：转写、渲染任务与只读渲染计划客户端。
- `backend/internal/editing`：语义渲染计划编译。
- `backend/internal/task`：本机转写/渲染/深度捕捉准入。`backend/internal/app/task_timeline.go`、`backend/internal/app/task_render.go`：领取后的转写与 native 渲染执行。
- `backend/internal/repository/project_workbench_read.go`：项目概览指标聚合（含成片完成度计数）。
