# 画布参考模板

## 导入与复用

在画布图片节点的提示词面板点击「参考模板」。导入一张自有或获准用于创作参考的 PNG、JPEG、WebP 图片，选择姿势、服装或角色用途，填写名称、标签、视角和补充说明。单张最大 12MB，最多 5000 万像素。模板库支持分类、名称/标签/视角搜索、筛选、收藏和最近使用。

「新建组合」可分别选择一张角色、姿势和服装图，保存为可重复调用的组合。组合保存自己的图片引用和用途快照，删除原单图模板不会使已保存的组合失效。编辑单图模板支持名称、分类、标签、视角及用途说明；更换图片时重新导入单图模板。

模板库提供原站与 RuiC 图鉴入口，不预装或批量抓取第三方图片。原站单图应由用户按其授权自行取得后导入；不能将代码开源许可视为图片再分发许可。

## 应用到节点

选择模板后点击「应用到当前节点」，图片会以参考节点和连线进入当前画布。模板角色用途在真正准备生成输入时按实际图片编号编译：角色图约束身份与面部，姿势图参考动作和构图，服装图参考款式、颜色与材质。用途说明提醒模型不要将姿势人台的脸、肤色或服装当作角色设定。

应用保留主体提示词、模型与渠道选择，不会自动提交生成。替换同类模板只更新它的引用，已有手动图片引用按对象身份重新编号。重复应用复用未被手动替换的模板图节点；模板间共享图片时，移除其中一个模板仍保留另一个需要的连线。锁定或生成中的节点不能应用或移除模板。

节点面板及放大编辑面板显示当前模板与移除入口。移除只取消该模板拥有且没有其他模板需要的连线，不删除图片节点或用户手动加入的资源。模板图与已有参考合并后按当前模型的图片数量上限校验；超限时显示原因，不丢弃图片。图片参考沿用现有模型协议，不等于骨骼或 ControlNet 控制。

## 保存与隔离

模板目录和原始图片使用按用户 scope 隔离的 IndexedDB/localforage。图片以 SHA-256 去重；媒体及模板大 JSON 不写入 localStorage。模板可在同一账号的不同项目中选择，只有主动应用的参考才进入该项目画布，不会将其他项目资产混入当前画布。

导入只保存本机模板。应用时使用现有工作区图片资源服务，成功的资源绑定可复用；资源服务暂不可用时保留本机图片，并明确提示尚未写入资源服务。切换账号、切换目标项目/节点、关闭模板库或目标被删除时，未完成的应用不会挂到新的目标。

模板用途与引用快照随画布文档保存，刷新后恢复；本机模板库不是跨设备同步或素材导出包。删除模板只移除目录条目，保留可能仍被组合及项目引用的图片，物理资源清理继续遵循既有引用保护。
