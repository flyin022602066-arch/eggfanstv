# 看海与 nono 视频渠道

在模型管理中分别填写自己的渠道 API Key。两个渠道使用独立的协议、模型目录和凭据，参考素材沿用公网直链准备流程，本地素材通过 Uguu 转换。默认生成有声视频；请求不附加文档未支持的静音、人脸处理或其他渠道参数。

## 看海

默认地址为 `https://yioapp.top/openapi/v1`。创建使用 `POST /videos`，查询使用 `GET /videos/{id}`，完成后通过携带本站鉴权的 `GET /videos/{id}/content` 下载。

模型列表只收录视频模型。模型名称后展示目录返回的普通/会员积分价格，按条或按秒显示；目录返回账号实际价格时优先展示账号价。明确声明支持真人的模型追加「不卡人脸（渠道声明）」，不据模型名称猜测。维护中和关闭的模型保留状态标注，历史任务仍可查询。

原生请求使用 `duration`、`ratio`、`resolution` 及参考直链数组。`xianfeng-seedance-2.5` 有音视频参考时使用统一 `files`，保留真实格式、时长及签名直链，避免混用旧数组。查询始终使用看海本站任务 ID，不使用 `upstream_task_id`。

## nono

默认地址为 `https://sub-tz.top/prod-api/v1`，包含文档实际 cURL 使用的 `/prod-api` 前缀。创建使用 `POST /videos`，查询使用 `GET /videos/{task_id}`，结果来自 `results[].url`。

通过账号的模型目录拉取全部 `VIDEO` 模型，不再使用名称白名单，也不因规格或计费单位不同过滤视频模型。图片、文本和音频模型不收录；重复编码只展示一次。模型编码仍原样用于提交，保留中文、空格与大小写。以下为原有三个模型的目录示例，不是可拉取范围限制：

| 模型编码 | 公开目录参考价格 | 时长 | 参考素材 |
| --- | --- | --- | --- |
| 按条特惠seedance-2.5-720P 满血 | 5.5积分/条 | 5～30秒 | 30图、10视频、10音频 |
| 按条福利seedance-2.5-720P | 4.8积分/条 | 5～30秒 | 20图、5视频、5音频 |
| 按条seedance-2.5-720P 只支持参考图 | 3.5积分/条 | 固定30秒 | 9图 |

每次点击拉取/刷新模型时，重新读取渠道目录的 `specs[].price_credits` 和 `billing_unit`，更新模型名称后的价格；不使用内置参考价覆盖刷新结果。多规格分别显示规格与价格，按条和按秒区分展示，其他计费单位保留渠道原文；零积分正常显示，缺失或无效报价显示「价格未提供」，单位缺失时明确提示，不继续展示旧报价。这里的实时价格指最近一次成功刷新目录的报价，不是后台持续轮询或最终扣费承诺；积分不等同于人民币。

本次目录拉取优化不改视频提交格式和参数：原有三个模型仍使用 `spec: "720p"`、`count: 1`，时长、比例、分辨率置于 `params` 对象。参考素材仍通过 `image_urls`、`video_urls`、`audio_urls` 提交。不调用 Token 模型报价接口。

有任何参考素材时明确发送 `reference_mode: "omni"`，没有素材时发送 `reference_mode: "text"`；该字段是文档声明的 `params.referenceMode` 顶层写法。全能参考与文生视频的素材数量分别校验，不能让有图请求沿用文生视频的默认用途。

本地参考素材在任务执行时并发上传到 Uguu，全部取得直链后再发送视频生成请求；创建任务的校验允许这一自动上传流程。复用的 Uguu 链接先检查有效性，失效时从本地原文件重新上传，保持图片顺序和原始画质。任一素材准备失败会停止本次视频提交，并取消仍在准备的素材；不会将本地地址或内嵌图片直接交给 nono，也不会因此自动重复创建视频任务。

nono 的图片自动准备保留 Uguu 为主图床，遇到 502、限流、网络中断或上传超时等临时故障，重试后依次使用 Pone、Leopard Hosting 备用图床。不同图片保持并发，同一用户的相同原图合并上传；图片不压缩、不改顺序，模型 API Key、Cookie 和渠道请求头均不发送给图床。备用返回必须通过 HTTPS 域名白名单及图片内容探测，下载页面不能作为直链。Pone 使用 `POST https://pone.rs/upload` 的 `files[]`；Leopard 使用 `POST https://leopard.hosting.pecon.us/upload.php` 的 `uploadContent`，指定 `public=no`、`json=true`，不公开到最近上传列表，不使用用户原文件名。备用链接记录上传时间与 24 小时本地复用窗口，这不是图床保留期保证；在窗口内且可访问时复用，失效后从本地原图重新准备。每家图床单轮等待最多两分钟后进入下一家；用户取消时立即停止。图片会发送到公开第三方存储，可能长期保留，链接持有者可以访问，请勿用于私密资料；免费服务不提供可用性保证。Catbox、img.neko.airforce 未启用。视频、音频、其他渠道及手动「上传 Uguu」接口保持原流程，不切换备用图床。全部图床均失败时明确显示素材准备失败和各站点错误，不发送视频生成请求。

目录能力和 15000 字提示仅用于展示与参数建议；本地不以目录或旧配置限制 nono 的参考数量、大小、时长、输出规格或提示词。提交保持用户编辑后的全文和全部参考，不自动截断、删图或更换模型；超出实际能力时由 nono 返回错误，日志保留上游 HTTP 状态、错误码和说明。资源归属、文件读取与公网链接准备仍由本地检查。

## 删除与任务恢复

删除渠道会保存 `deletedChannelIds`，重启时不再自动补回。重新主动添加同 ID 渠道会清除删除标记。保存失败显示错误，不以临时界面移除冒充持久化成功。

视频提交后保留上游任务 ID，查询与下载异常通过原任务恢复，不因此重新创建付费任务。上游明确失败时保留原始失败说明。

nono 已取得上游回执的任务达到本地单轮等待时限后，继续查询原任务，不把本地等待超时当作上游生成失败；自动恢复保留现有 24 小时边界。手动「重新查询」包含视频下载和本地入库，使用独立的 10 分钟请求预算，不沿用普通业务请求的 4 秒超时，也不重新提交生成。

手动取回成功后清除当前失败摘要，保留历史请求证据并补记本次查询、下载结果。项目在查询结束或响应异常时都刷新原镜头任务与产物，避免后台已经入库而页面继续显示旧失败状态。
