## 入口与配置

侧栏「音乐导演台」对应 `/music`。选择模型配置中已有的自定义渠道，沿用该渠道的 Key 和自定义请求头；不修改文本、图像、视频或语音合成的模型选择。默认推荐 `https://api.eggfans.com`，模型版本在导演台通过 `mv` 单独选择，默认 `chirp-v5`。

Suno 使用根路径 `/suno/...`，不是 OpenAI 的 `/v1/audio/speech`。渠道地址末尾的 `/v1` 或 `/suno` 在音乐请求中归一化，其他路径前缀保留。自定义渠道仍通过 `channelRequest`、`createChannelTransport` 与本地 `/api/ai/custom` 转发，Key 不出现在 URL、工作区草稿或音乐历史里。后端仅放行已发布的 Suno 路径、方法和查询参数，保留原有鉴权、限流及私网限制。

## 参数合同

协议依据 Eggfans 文档 MCP 的 `suno` 平台发布内容，共 26 个接口。定义与校验位于 `web/src/lib/suno-contract.ts`，导演台参数控件与 API 请求共用该合同。

- 普通音乐创作：`POST /suno/submit/music`。灵感模式只提交 `gpt_description_prompt`，自定义模式只提交 `prompt`；`tags`、`title`、`make_instrumental` 分别控制风格、标题和纯音乐。
- 模型版本：`chirp-v3-0`、`chirp-v3-5`、`chirp-v4`、`chirp-v4-5`、`chirp-v5`、`chirp-v5-5`、`chirp-v6`、`chirp-v6-wild`、`chirp-v6-mini`。Persona 一致性创作使用文档指定的 `chirp-v3-5-tau` 或 `chirp-v4-tau`。
- 续写：`continue_clip_id` 使用查询结果中的歌曲 clip ID，而非提交返回的任务 ID；`continue_at` 使用秒。
- 局部编辑：使用 `metadata_params` 中的替换区间、上下文区间、对齐提示和嵌套 `metadata.infill_lyrics`；起止时间由本地校验。
- Persona：先生成源歌曲，再以 `root_clip_id`、人声区间与 `user_input_styles` 创建 Persona；后续创作提交真实 `persona_id` 和对应 `artist_clip_id`。
- 翻唱、重制、伴奏、混搭与音效使用各自的原生字段。切换任务时不提交其他任务残留字段。文档未发布的图生曲、视频生曲扩展字段仅通过显式高级 `metadata_params` JSON 编辑，不推测字段名。
- 工具包含歌词生成、风格扩写、两轨/十二轨分离、调速、淡入淡出、拼接、封面和标题管理、MP4、WAV、MIDI、波形、歌词时间线、作品和积分查询。

上传参考音乐使用 `/suno/uploads/audio` 的 JSON URL 合同，不是 multipart。导演台选择本地参考音频后先保存到本地资源库，再通过现有临时上传服务获取可访问 URL。`speed_multiplier` 范围为 0.25–2，`speed_multiplier_fix` 保持布尔类型；`MUSIC_COPYRIGHT` 的文档标注为消耗 30 积分，仅在用户明确提交该操作时调用。播放调速的 `speed` 范围为 0.25–4，与上传调速分开。

## 任务与资源

画布音频节点选择 Suno 后会显示专用音乐参数，包括上述模型版本、创作模式、纯音乐、风格、标题和各任务的片段/区间参数。节点提示词作为当前模式的音乐描述或歌词；不再显示或发送 Alloy、语速等配音参数。节点参数随画布保存。

画布中的文本和音频节点可打开同一音乐导演台。导演台读取当前节点与直接连入的文本、Suno 音频节点；文本内容可写入歌词，已关联渠道的曲目可携带 clip ID 和 task ID 用于续写或其他 Suno 操作。生成曲目可写回音频节点，歌词可更新文本节点或生成关联歌词节点。导演台草稿按画布项目和节点隔离，曲目关联保留渠道与任务标识，不把 ID 当作音频 URL。

画布通过持久化的后端音乐任务调用 `/suno/submit/music`，提交响应的字符串 ID 在请求日志和任务状态中记录。已有 ID 的恢复只查询 `/suno/fetch/{id}`，不重复提交。查询兼容结构化、JSON 字符串和 Base64 UTF-8 数据；每首歌曲下载到本地资源后再标记完成。一次返回多首时，在节点播放器的「Suno 歌曲版本」中切换。

所有音频结果都校验实际音频内容。HTTP 200 中的 `{"msg":"401","code":401}` 等错误正文会报告业务错误，不能作为音频保存并标记生成成功。

音乐草稿、参数、渠道 ID 和任务历史保存在按用户 scope 隔离的 localforage。提交前先保存本地任务；返回的字符串任务 ID 原样保存，不能经 JavaScript Number 丢失精度。重新打开导演台后继续查询已有任务，不重新提交创作。

每个渠道、每个工具操作分别保留上次参数；切换到分轨、调速等工具后再回到创作，原模型和歌词仍保留。工具返回的资源链接在结果面板显示；Persona 结果中包含真实 `persona_id` 时可一键填入歌手风格一致创作，继续填写歌词后提交。

普通任务查询 `GET /suno/fetch/{id}`；MP4 使用 `GET /suno/act/mp4-state?taskBatchId=...`。查询失败只记录同步中断并退避重查，不将上游任务改判失败。提交响应丢失且没有 ID 时保留「提交未确认」，必须核对渠道任务记录，不能自动重发。修改渠道地址后拒绝把旧任务 ID 发给另一个地址。

已完成曲目的所有返回片段分别保留。导演台通过 `POST /resources/suno-media` 取回原音频或歌曲视频，再持久化素材记录；不使用桌面版已移除的 `/resources/import`。取回由本地后端执行，校验媒体实际内容、大小、外部地址与重定向，不向媒体 CDN 发送渠道 Key、Cookie 或桌面凭据。相同曲目的同一次操作幂等复用本地文件，不把普通歌曲与 WAV 操作的结果混用。

重新打开导演台会继续恢复“上游已成功、本地尚未保存”的曲目，失败时退避重试，只下载已有结果，不重新提交创作。下载完成后立即保留本地资源引用，素材记录写入中断不会要求重新下载。试听和波形优先使用鉴权读取的本地 Blob；尚未落盘的歌曲在首次试听或加载波形时先取回原文件，避免浏览器直接跨域读取 CDN。媒体保存失败不改变上游成功状态；Windows 导出沿用原生文件保存入口。页面循环与区间选择是本地编辑状态，只有明确提交对应编辑操作时才调用模型。

## 曲库与创作助手

已完成的音频曲目会显示在导演台右侧「曲库」页签；数据从当前用户隔离的音乐任务记录恢复，媒体文件保存在本地资源库。曲库只收录已完成并含音频的歌曲，可搜索、试听、下载或加入素材库。

创作工作台的 AI 音乐创作入口使用已配置的文本模型，并仅展示文本能力模型。内置 Skill 覆盖原创歌词、影视配乐灵感、曲风与编曲、歌词润色、纯音乐主题；生成的灵感描述、歌词或标签可填回 Suno 参数。该入口只创建文本任务，不会自动提交 Suno 歌曲任务。

## 歌词驱动的 MV 制作

MV 制作区与预览任务区之间的分隔条支持左右拖动，宽度比例按用户记忆。方向键可微调，双击恢复默认；空间不足时自动上下排列。制作区内的资产卡片和分镜卡片随可用宽度自动排列为多列。拖动仅按动画帧更新布局，释放后保存比例，不触发生成任务或写入创作草稿。

MV 工作流先读取曲库歌曲的歌词，由已配置的文本模型按歌曲时长拆成连续 30 秒段（末段为剩余时长），同时提取可复用角色、场景和道具资产。用户可以修改歌词、整体视觉风格、资产生图提示词和每段视频提示词；歌词变更后必须重新拆解。

MV 主角人脸预设与项目角色资产共用上传校验、男主/女主绑定和角色三视图模板。角色卡片可直接选择人脸参考；已上传但未绑定时会提示，并阻止静默退回纯文本生图。绑定角色的原参考图片进入图片编辑或图生图协议，服装与造型仍按 MV 设定设计。角色绑定保存在当前用户的 MV 草稿中；更换或解绑人脸只会清除对应角色的旧参考图。重新拆解同一歌曲时按唯一同名角色恢复绑定；切换歌曲、角色改名或存在重名时需要重新绑定，避免误用其他角色的面孔。

资产图片设置按角色、场景、道具分别保存模型、尺寸比例、画质及模型支持的其他图片参数，不修改视频或其他渠道配置。角色设定图默认横向 3:2，场景默认沿用 MV 画幅，道具默认 1:1；可在生成前调整。单项生图只锁定当前资产，各资产的进度和错误独立显示；批量补齐最多同时处理三项，失败项不阻断其他资产。切换歌曲、重新拆解或生成期间修改资产设定后，旧请求结果不会覆盖新的资产内容。

资产图片通过已配置的图片模型逐项生成并保存到本地资源库；绑定男女主人脸的角色在单张及批量生图时使用相应人脸参考，并沿用项目三视图模板。每段视频只绑定该段引用的资产图，并按段起点裁切歌曲音频；任务逐段提交，已提交任务继续沿用原有自动查询和本地取回流程。MV 与项目镜头共用视频参数解析和兼容性校验，包括模型能力、时长、画幅、分辨率、图片/音频参考、生成声音、水印及渠道人脸处理设置。为保证资产参考，每个 MV 视频模型必须同时支持音频和图片参考；批量工作流要求模型支持 30 秒输出。提交结果不确定时不会自动重复提交。

## 验证边界

协议和状态恢复使用离线模拟响应验证，浏览器检查使用隔离的测试数据与音频。自动化验证不读取真实 Key、不联系已配置模型网关，不产生实际音乐生成费用。真实上游行为仍以用户授权后的提交为准。
