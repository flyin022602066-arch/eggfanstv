模型配置内置 **Mints Seedance（自动 URI）** 渠道。填入该平台 API Key；Base URL 和模型 ID 均可修改。文档默认地址为 `http://open.mints-id.com`，如平台提供 HTTPS 地址可直接修改。

文档列出的模型为 `doubao-seedance-2-0-260128`、`doubao-seedance-2-0-fast-260128`、`doubao-seedance-2-0-mini-260615`。Seedance 2.5 的准确模型 ID 需向平台确认后填写，不能套用其他网关的 ID。能力与参数页允许修改参考数量、时长、尺寸等约束，应与平台开通模型的能力一致。

## 视频节点的自动流程

用户连接原始图片、视频、音频或通过 `@资产` 引用后，直接点击生成：

1. 后端读取当前用户的本地素材，检查已有 Uguu 临时 URL 的过期时间和可访问性；失效时上传原始文件并保存新链接。
2. `POST /api/seedance/assets`，传 `URL`、`AssetType`（Image/Video/Audio）、`Name`。不传 Force；未填写 GroupId 时使用平台默认组。
3. 保存 `Result.Id`，每 3 秒查询 `GET /api/seedance/assets/{id}`。等待 Active，再将 `asset://{id}` 绑定原素材；Failed 或未知状态会停止视频提交。
4. 提交 `POST /api/v3/contents/generations/tasks`。正文使用 `model`、`content[]`、`resolution`、`ratio`、整数 `duration`、`generate_audio`、`watermark`。图片、视频、音频分别保留 `image_url`、`video_url`、`audio_url` 对象和 role。首尾帧及同类参考顺序不变，`@图片1` 等不会改写成其他素材的 URI。
5. 保存创建返回的任务 `id`，轮询同路径 `/{id}`。成功读取 `content.video_url` 并下载到本地；媒体扩展名按实际类型处理。恢复已提交任务沿用原 ID，不重新提交生成。

Uguu 图片上限 30MB，单个视频或音频上限 128MiB；超过上限需先压缩。只有远程失效链接且没有原始素材时无法重传，应重新导入原件。

## 参数与持久化

模型的「配置使用 → 能力与参数」提供 Mints 专属资产组 ID、seed、service_tier、camera_fixed、draft。资产组 ID 留空使用平台默认组；真人素材需用户先在平台完成本人 H5 认证，填写认证后的组 ID，自动绑定不代替认证。

参数保存到模型的 `defaultOptions`，生成时合并到 `metadata.providerOptions["mints-seedance-video"]`，零种子及 false 值保持不变。资产组 ID 只用于素材接口，不泄漏到视频正文。其他渠道命名空间中的参数不会混入。

原件保存在工作区资源目录，绑定复用 `eggfans_asset_bindings` 表，通过独立 Mints scope 隔离用户、平台地址、Key 和请求头；同素材不同组也独立。再次使用时查询平台状态，已就绪 URI 直接复用，平台资产 404 时重新上传绑定。处理中 ID 已持久化，中断或超时后重试继续查询。画布原图不会被 `asset://` 替换。

视频生成复用宿主持久任务、60 分钟视频超时及结果下载流程。平台返回的视频 URL 有效 24 小时；文档注明 2.5 的结果下载最多 100 次，应及时保存本地。
