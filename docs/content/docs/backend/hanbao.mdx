# 憨包账号与飞狐接码

在「设置 → 模型管理」找到「憨包」，点击「账号管理」。本渠道使用独立 CLI 和 Edge/Chrome 浏览器登录资料，支持 Windows。它与普通 API Key 渠道分别配置。

## 登录与模型

填写账号标签，点击「登录 / 添加账号」，在弹出的浏览器完成扫码或手机号登录，然后刷新账号并点击「用于生成」。手机号和验证码需要手动填写；组件不提供自动填表命令。「检查登录」会联网校验，本地账号清单中的已登录标记不代表当前网页会话一定有效。

| 模型名称 | 实际模型参数 |
| --- | --- |
| Seedance 2.5 | `seedance_v2.5` |
| Seedance 2.0 Mini | `seedance_v2.0_mini` |
| Seedance 2.0 Fast | `seedance_v2.0` |

- 时长为 4～30 秒整数，默认 5 秒；0 不是自动时长。
- 比例支持 `16:9`、`9:16`、`1:1`、`4:3`、`3:4`。
- 支持文字生成和图片参考生成，最多 9 张参考图，合计不超过 4 MiB。超限直接拒绝，避免组件静默丢图。
- 不支持生图、参考视频、参考音频、分辨率、FPS、随机种子和负面提示词。
- 套餐标签、每日条数和秒数是本地调度阈值；重置计数不会增加上游真实额度。

「调用参数」允许选择 `auto/canvas/chat`，网页版本默认 `20800`，PC 版本默认 `3.43.2`。画布尝试次数默认 1；调大可能由组件内部重复提交并额外消耗额度。

## 飞狐接码

入口只存在于憨包账号管理中。填写用户中心「API 对接」的 API Key 与 API 密钥，保存后点击连接，再搜索并选择已审核的豆包项目，保存项目 ID。默认 HTTPS 基础地址为 `https://my.feihu2026.com/api/sms`；密钥输入留空会保留原值。

取号时绑定憨包账号标签，可筛选运营商、省份、实卡/虚卡、包含或排除号段；高级筛选支持指定号码、作者、取号模式、对接码和混入香港号码。没有预置作者或佣金账号。`isp=hk` 为仅香港，`hk=1` 为混入香港，两者含义不同。

短信轮询间隔至少 10 秒；只在用户启用自动收码时轮询，关闭弹窗即停止前端轮询。可手动查询、释放或拉黑本模块创建的订单，不提供全平台释放、按任意订单或号码查询等通用接码入口。后端取号前再次核对项目名称、ID 和审核状态；订单绑定原平台凭据和项目，不能用另一平台账号操作。存在等待短信的订单时，先收码或释放，再修改接码凭据或项目。

后端使用表单 POST：`login` 传 `user/pass`，其他接口传 `token`；同时校验 HTTP 状态和上游业务 `code=200`。凭据不放 URL。平台文档见 [飞狐 API 文档](https://my.feihu2026.com/document)。

## 本地数据与任务

发布目录 `tools/hanbao` 保存 CLI 与原始参数合同。CLI SHA-256 固定为 `1e548f69030af8790d20a0fcd42ec2207a3e35b15ecb4c70021f4e24aad72866`，运行前检查，不执行被替换的文件。管理员可通过 `CANVAS_HANBAO_CLI` 指定相同哈希的组件文件。

账号和加密配置保存在当前工作区的 `hanbao` 子目录。子进程同时隔离 `DOUBAO_BASE_DIR` 与 `APPDATA`，不自动迁移其他软件的账号。飞狐配置和短信订单使用工作区密钥加密；访问 Token 只保留在后端进程内，设置读取仅返回是否已保存凭据。

生成沿用持久任务队列。提交后将完整 `submit_id` 和返回的实际 `account` 一起保存，并在当前任务租约内原子登记提交记录。组件可能轮换账号，查询不会改用用户后来选择的账号。网络中断、`query_error` 和等待超时继续回查原任务；提交响应不确定时停止自动重发。账号管理与生成互斥，已受理的活动任务也会阻止修改账号配置或清理浏览器资料。

不支持上游取消；「仅本地停止」结束本机等待，上游仍可能运行或计费。不要把进程退出、HTTP 成功或本地登录标记当作生成完成；仅在 `gen_status=success` 且存在视频 URL，下载和本地资源保存成功后交付结果。

## 本地 HTTP 接口

这些接口使用当前本地工作区权限与 BeefTV 的 `{ code, data, msg, reason }` 信封。

| 方法与路径 | 请求与用途 |
| --- | --- |
| `GET /api/hanbao/status` | 读取组件可用性及脱敏设置；不会登录、取号或生成 |
| `PUT /api/hanbao/settings` | 保存账号、网页调用参数及飞狐配置，最大 16 KiB |
| `POST /api/hanbao/accounts/:action` | `accounts/login/checklogin/open/logout/delete-account/set-plan/reset-quota`；JSON 为 `account/plan/dailyLimit/dailySeconds`，最大 4 KiB |
| `POST /api/hanbao/sms/:action` | `connect/info/projects/orders/receive/message/release/blacklist`；JSON 为 `account/orderId/filters`，最大 8 KiB |

账号操作忙时返回 HTTP 409、`reason=conflict`。无效参数或平台调用失败返回真实失败状态，不伪装业务成功。CLI 登录最长等待 300 秒，前端请求超时另留退出时间。
